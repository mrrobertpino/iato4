Quick recap, not a new unit: What if part of a message gets lost on the way?

With protocols like TCP, computers can acknowledge received data (ACK), notice missing data, and resend it if necessary. Different protocols handle reliability differently.

The big idea: The Internet isn't just computers sending data. They communicate and coordinate so information can get where it needs to go.

Part 1: GUIs, From Commands to Clicks

GUI (pronounced “gooey”) stands for Graphical User Interface. An interface is how a person interacts with a device or program. A GUI uses windows, icons, pictures, buttons, and menus to make that interaction visual.

Part 3: What Does a Browser Do?

Your browser receives webpage resources, interprets the HTML and CSS, runs JavaScript when appropriate, and renders the webpage you see on screen.
